# Literature Review

This folder contains structured literature notes for the thesis:

**Multiscale data visualization and event analysis for a distributed underwater acoustic monitoring system**

## Purpose

The goal of this literature review is not only to summarize existing work, but to:

- understand how DAS data is used in underwater acoustics;
- analyze existing visualization and processing tools;
- study approaches to acoustic event detection;
- justify design decisions of our project.

## Structure

The literature is organized into several categories:

- DAS fundamentals
- Underwater DAS and whale monitoring
- Tools and visualization systems
- Acoustic event detection
- ML and feature-based approaches

Each source is documented as a separate note.

## Outcome for the project

This literature review supports:

- State of the Art section of the thesis
- Methodology design
- Justification of DAS-centered visualization approach
